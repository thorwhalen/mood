mood.dataset_makers

Tools to make datasets for training and testing models (for semantic attribute etc.)

mood.dataset_makers.make_semantic_attributes_dataset(semantic_attributes: str | Mapping, store: str | MutableMapping = '/home/runner/.config/mood/semantic_attributes', *, n_examples: int = 1000, batch_size: int | None = 100, start_batch_idx_at: int = 0, save_key: Callable = <function default_save_key>, verbose: int = 0, **dataset_maker_kwargs)[source]

Gather data for each semantic attribute and save it to the store.

Parameters: - semantic_attributes: Mapping of attribute names to their descriptions - store: Storage location (string path or MutableMapping) - n_examples: Total number of examples to gather per attribute - batch_size: Number of examples per batch; if None, gather all examples in one batch - start_batch_idx_at: Starting index for batch numbering - save_key: Function to generate save keys - verbose: Verbosity level (0=quiet, 1=attribute progress, 2=batch progress) - dataset_maker_kwargs: Additional kwargs for semantic_attribute_examples_for_attribute

WARNING: Some models aren’t very good at generating the requested number of examples. They may generate fewer or more than requested. This is a known issue with LLM models.

>>> store = {}
>>> attributes = {"color": "description of color"}
>>> make_semantic_attributes_dataset(attributes, store, n_examples=3, batch_size=2)
>>> len(store)  # Two batches saved
2
